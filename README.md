# UnitWatch

_A simple Python application for tracking daily electricity usage, monitoring unit consumption, and estimating future usage based on your current average._

---

## Features

- Database
- Add meter readings
- View previous readings
- Track daily unit usage
- Store readings by date
- Calculate usage between readings
- Calculate average daily usage
- Simple and clean GUI

---

## Tech stack

- Python 3
- PyQt6
- Duckdb (for database)
